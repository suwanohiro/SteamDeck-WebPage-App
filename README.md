# SteamDeck-WebPage-App

SteamDeckで、特定のページを全画面で開くためのツール<br>
Webサイトであれば基本的にどのサイトでも表示可能です。<br>
ゲームモードから、YouTube等をゲームソフトと同様に起動できるようになります。

## 利用方法

- Steamの「非Steamゲームを追加」から、 `run.sh` を選択する

> [!IMPORTANT]
> このとき、 `.AppImage` ファイルを選択しないように注意

- Steam側で、追加された `run.sh` 項目のプロパティを開く
- 起動オプションの部分に表示させたいURLを入力する
